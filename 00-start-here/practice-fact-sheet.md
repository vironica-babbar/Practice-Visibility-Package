# Practice Fact Sheet

**Fill this in first.** Every template in this package uses the blanks below.
Write each answer exactly the way you want it to appear everywhere online,
then copy it exactly each time. Small differences like "Ste" versus "Suite"
or two different phone numbers make it harder for Google and directories to
match your listings, and harder for patients to trust them.

> Do not put any patient information on this sheet. It holds facts about the
> practice only.

A fictional example is shown in *italics* under each blank.
