# Insurance Directory Templates

Copy-paste templates for keeping your insurance listings accurate. Read
`insurance-directory-guide.md` first.

> **No patient information in any of these messages.** They're about your
> providers and locations only. All example names and numbers are fictional.

## Template 2: Correction request email

**When to use:** you found a wrong listing and the insurer has no online form.
**Where to send:** the insurer's provider relations or provider data email,
listed in your provider manual or on the insurer's provider website.

**Subject:**
```
Provider directory correction – [PROVIDER NAME], NPI [PROVIDER NPI] – [INSURER NAME]
```

**Body:**
```
Hello,

Please update the provider directory listing below. The current listing is inaccurate.

Provider: [PROVIDER NAME], [CREDENTIALS]
Individual NPI: [PROVIDER NPI]
Group: [PRACTICE NAME], Group NPI [GROUP NPI]
Tax ID: [TAX ID]
Plan(s) / network(s): [PLAN NAMES]

What the directory currently shows:
[FIELD]: [WRONG INFORMATION]

What it should show:
[FIELD]: [CORRECT INFORMATION]

The same information has been updated in our CAQH ProView profile (CAQH ID [CAQH ID]), attested on [DATE].

Please confirm when the change has been made. You can reach me at [YOUR NAME, ROLE], [PHONE], [EMAIL].

Thank you,
[YOUR NAME]
[ROLE], [PRACTICE NAME]
```

> The Tax ID goes only to insurers you're contracted with, never to
> directories or public sites.

## Template 3: "Accepting new patients" status change

**When to use:** the day a provider's caseload fills up, or opens again.

**Subject:**
```
Directory update – new patient status – [PROVIDER NAME], NPI [PROVIDER NPI]
```

**Body:**
```
Hello,

Please update the new patient status for the provider below, effective [DATE].

Provider: [PROVIDER NAME], [CREDENTIALS], NPI [PROVIDER NPI]
Group: [PRACTICE NAME], Group NPI [GROUP NPI]
Location: [FULL ADDRESS]
Plan(s): [PLAN NAMES]

New patient status: [Accepting new patients / Not accepting new patients / Accepting new patients – current wait approximately WEEKS weeks]

Please confirm once updated. Contact: [YOUR NAME, ROLE], [PHONE], [EMAIL].

Thank you,
[YOUR NAME], [PRACTICE NAME]
```

## Template 4: Provider leaving or location closing

**When to use:** as soon as a departure date or closure is confirmed. Leaving
a departed provider listed is the classic "ghost listing."

**Subject:**
```
Directory update – provider departure – [PROVIDER NAME], NPI [PROVIDER NPI]
```

**Body:**
```
Hello,

Please update your directory for the change below.

Provider: [PROVIDER NAME], [CREDENTIALS], NPI [PROVIDER NPI]
Group: [PRACTICE NAME], Group NPI [GROUP NPI]
Change: [Provider will no longer practice at LOCATION / Location closing]
Effective date: [DATE]
Plan(s): [PLAN NAMES]

[OPTIONAL: Patients may continue care at our practice with PROVIDER NAMES at the same location.]

Please confirm once the listing has been updated. Contact: [YOUR NAME, ROLE], [PHONE], [EMAIL].

Thank you,
[YOUR NAME], [PRACTICE NAME]
```

the reference number** in the tracker below.

## Copywriting check before you send any insurer message

- [ ] One provider and one type of change per email. Mixed requests get partly done.
- [ ] NPI numbers on every message
- [ ] Wording copied **exactly** from the data sheet ("Suite 200," not "Ste 200")
- [ ] Plain, factual tone. No emojis, no urgency language, no complaints about past errors.
- [ ] No patient information of any kind
- [ ] Saved a copy with the date
